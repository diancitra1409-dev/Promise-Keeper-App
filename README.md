# 🎯 Promise Keeper App

Aplikasi pelacak komitmen dan target pribadi yang membantu pengguna mengelola janji, tujuan hidup, serta memantau tenggat waktu secara terstruktur[cite: 18, 19].

---

## ✨ Fitur Utama

- **Autentikasi Pengguna:** Akses akun aman dengan fitur Register dan Login[cite: 20].
- **Dashboard Ringkas:** Menampilkan metrik *Total Promise*, *Active Promise*, dan daftar *Upcoming Deadlines*[cite: 18].
- **Pelacakan Komitmen:** Tandai komitmen yang masih berjalan (*Active*) atau sudah selesai (*Completed*)[cite: 18, 19].
- **Manajemen Janji:** Formulir lengkap untuk menambah, memperbarui deskripsi/tenggat waktu, dan menyimpan progres[cite: 18, 21].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend / Database:** Node.js, Express.js, MySQL (sesuaikan dengan file di repo kamu)
